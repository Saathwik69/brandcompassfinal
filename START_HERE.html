Run it in three steps.

1

Install Node.js 24

Download it from nodejs.org. Reopen your terminal after installation. Node 18 and 20 are too old for this project.

2

Open the project folder

Extract the complete ZIP. Open the BrandCompass folder in VS Code, then choose Terminal → New Terminal.

3

Start the app

npm start

Open http://localhost:3000 and choose Explore the live demo.

Keep the terminal open. No npm install is needed. Windows users can double-click START_WINDOWS.bat; macOS/Linux users can run bash start.sh. This guide opens directly; the application needs its server.

Your three-minute demo.

  1. Open A better everyday bottle. Show the unsupported 48 hours claim and its approved evidence.
  2. Apply a preferred-word suggestion. Show the new revision.
  3. Use the text in approved_caption.txt. Set the declared text/background colours to #172B26 and #FFFFFF, then save and review.
  4. Submit for approval. Switch the demo role to Manager and approve with a reason.
  5. Show Insights, Audit trail, revision history and Export.

Demo role switching is isolated to demo workspaces. Use a registered workspace for records you want to reopen after signing out.

Explain the AI honestly.

The default engine uses deterministic rules and lexical retrieval. It flags detected claims that lack an exact current approved statement. Its check score is not an accuracy percentage. Optional generative AI is implemented and can be enabled with your own server-side OpenAI API key; live paid API use was not tested. It adds advisory findings and never approves a draft.

The supplied planning PDF proposed a different stack. The delivered build uses JavaScript, Node 24 and SQLite for a simple local demonstration, plus a Worker/D1 hosting build. It is a hackathon prototype; OCR, semantic image recognition and production SSO are future work.
